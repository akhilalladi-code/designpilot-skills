# Typography Skill

## Objective
Choose and apply type deliberately. Typography must support the message, audience, language, brand character, and viewing conditions.

## Required inputs
Collect the format, dimensions, audience, language/script, brand personality, available fonts, reading distance, and accessibility requirements. If absent, label assumptions.

## Workflow
1. Identify the communication role: display, editorial, interface, data, or long-form reading.
2. Establish hierarchy levels: display, heading, subheading, body, caption, label, and utility text.
3. Select typefaces based on legibility, character, language coverage, licensing, and available weights.
4. Define a restrained type scale appropriate to the medium. Use relative sizing and line-height, not arbitrary isolated sizes.
5. Set measure, alignment, paragraph spacing, tracking, and line length for comfortable reading.
6. Test real content, including long headings, numerals, punctuation, mixed scripts, and small screens.
7. Specify fallbacks and font-loading behavior for digital work.

## Pairing principles
- Prefer one versatile family or two complementary families.
- Give each family a clear role; avoid pairing fonts that compete for the same voice.
- Compare x-height, proportions, contrast, and rhythm.
- Do not use a typeface solely because it is fashionable.

## Quality checklist
- Clear hierarchy without relying on color alone
- Comfortable body-text size and line length
- Adequate line-height and paragraph separation
- Strong contrast at actual output size
- Correct glyph coverage for every required language
- Verified font license and embedding permissions
- Responsive behavior and sensible fallback fonts

## Output format
Provide font recommendations with rationale, role mapping, type scale, spacing guidance, responsive adjustments, licensing notes, and a test checklist.

## Guardrails
Never assume a font is free for commercial use. Verify its license from the font publisher or repository. Do not distort type to force a fit; revise the copy, layout, or scale instead.
