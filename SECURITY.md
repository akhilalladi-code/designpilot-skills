# Security Policy

## Scope

DesignPilot Skills is primarily a collection of Markdown instructions and lightweight validation scripts. It does not currently require secrets, credentials, or runtime access to user systems.

## Reporting a concern

Please do not publish sensitive details in a public issue. Contact the repository owner through the contact options on their GitHub profile and include:
- A clear description of the issue
- Steps to reproduce, if applicable
- Potential impact
- A suggested mitigation, if known

Please allow maintainers reasonable time to investigate before public disclosure.

## Safe usage

Review AI-generated outputs before production use. Do not provide private client data, passwords, API keys, or confidential material to an AI system unless you have permission and understand that system's data-handling terms.
